## Problem Statement
Telecom operators lose revenue when subscribers leave unnoticed and when
unpaid balances are not tracked per customer.

## Objectives
**Main objective:** Build an Oracle PL/SQL database that manages telecom
subscriptions, billing and churn risk.

**Specific objectives:**
1. Store customers, contracts, services, invoices and payments in 3NF tables.
2. Calculate a churn-risk score for each subscriber with a PL/SQL function.
3. Enforce business rules with triggers and keep an audit log of changes.
4. Flag high-risk customers automatically with a scheduled job.

## Data Source
Telco Customer Churn (IBM sample data, via Kaggle), 7,043 customers.
https://www.kaggle.com/datasets/blastchar/telco-customer-churn
Note: invoices and payments will be generated by procedures (simulated).

## Innovation
Advanced analytics: a churn-risk score shown live from the Oracle database.

## Planned Tables
CUSTOMER, CONTRACT_TYPE, SERVICE_PLAN, SUBSCRIPTION, PAYMENT_METHOD,
INVOICE, PAYMENT, CHURN_ALERT, AUDIT_LOG

## Planned PL/SQL Features
- Procedures: generate_invoice, record_payment
- Function: calc_churn_risk
- Cursor: monthly billing loop over active customers
- Packages: pkg_billing, pkg_churn
- Triggers: block cancellation with unpaid balance, audit log
- Exceptions: overpayment, unknown customer
- Scheduler job: nightly flagging of high-risk customers
